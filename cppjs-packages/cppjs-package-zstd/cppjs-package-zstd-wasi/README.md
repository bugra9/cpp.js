# @cpp.js/package-zstd-wasi

The **WASI** build of the precompiled **zstd** library, built with [cpp.js](https://cpp.js.org).

> For installation and usage, see the main package: **[@cpp.js/package-zstd](https://www.npmjs.com/package/@cpp.js/package-zstd)**.

## Supported targets
- WASI (`wasm32-wasip1`) — single-threaded command modules; run with `wasmtime -W exceptions=y`
