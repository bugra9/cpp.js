# @cpp.js/package-proj-wasi

The **WASI** build of the precompiled **PROJ** library, built with [cpp.js](https://cpp.js.org).

> For installation and usage, see the main package: **[@cpp.js/package-proj](https://www.npmjs.com/package/@cpp.js/package-proj)**.

## Supported targets
- WASI (`wasm32-wasip1`) — single-threaded command modules; run with `wasmtime -W exceptions=y`
