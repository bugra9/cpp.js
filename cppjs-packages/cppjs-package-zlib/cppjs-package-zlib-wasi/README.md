# @cpp.js/package-zlib-wasi

The **WASI** build of the precompiled **zlib** library, built with [cpp.js](https://cpp.js.org).

> For installation and usage, see the main package: **[@cpp.js/package-zlib](https://www.npmjs.com/package/@cpp.js/package-zlib)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
