# @cpp.js/package-lerc-wasi

The **WASI** build of the precompiled **LERC** library, built with [cpp.js](https://cpp.js.org).

> For installation and usage, see the main package: **[@cpp.js/package-lerc](https://www.npmjs.com/package/@cpp.js/package-lerc)**.

## Supported targets
- WASI (`wasm32-wasip1`) — single-threaded command modules; run with `wasmtime -W exceptions=y`
