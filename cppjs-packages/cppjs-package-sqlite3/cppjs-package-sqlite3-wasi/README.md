# @cpp.js/package-sqlite3-wasi

The **WASI** build of the precompiled **SQLite3** library, built with [cpp.js](https://cpp.js.org).

> For installation and usage, see the main package: **[@cpp.js/package-sqlite3](https://www.npmjs.com/package/@cpp.js/package-sqlite3)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
