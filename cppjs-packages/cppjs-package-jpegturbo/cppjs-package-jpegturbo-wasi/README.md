# @cpp.js/package-jpegturbo-wasi

The **WASI** build of the precompiled **libjpeg-turbo** library, built with [cpp.js](https://cpp.js.org).

> For installation and usage, see the main package: **[@cpp.js/package-jpegturbo](https://www.npmjs.com/package/@cpp.js/package-jpegturbo)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
