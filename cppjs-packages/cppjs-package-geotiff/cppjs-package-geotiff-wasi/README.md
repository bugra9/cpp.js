# @cpp.js/package-geotiff-wasi

The **WASI** build of the precompiled **libgeotiff** library, built with [cpp.js](https://cpp.js.org).

> For installation and usage, see the main package: **[@cpp.js/package-geotiff](https://www.npmjs.com/package/@cpp.js/package-geotiff)**.

## Supported targets
- WASI (`wasm32-wasip1`) — single-threaded command modules; run with `wasmtime -W exceptions=y`
