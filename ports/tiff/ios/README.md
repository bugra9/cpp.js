# @crossbind/port-tiff-ios

The **iOS** build of the precompiled **TIFF** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-tiff](https://www.npmjs.com/package/@crossbind/port-tiff)**.

## Supported targets
- iOS device — `arm64`
- iOS Simulator — `arm64` (Apple Silicon)
