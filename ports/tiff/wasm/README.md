# @crossbind/port-tiff-wasm

The **WebAssembly** build of the precompiled **TIFF** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-tiff](https://www.npmjs.com/package/@crossbind/port-tiff)**.

## Supported targets
- WebAssembly (`wasm32`) — single-threaded
- WebAssembly (`wasm32`) — multi-threaded (needs `SharedArrayBuffer`; serve with COOP + COEP headers)
