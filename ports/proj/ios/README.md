# @crossbind/port-proj-ios

The **iOS** build of the precompiled **PROJ** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-proj](https://www.npmjs.com/package/@crossbind/port-proj)**.

## Supported targets
- iOS device — `arm64`
- iOS Simulator — `arm64` (Apple Silicon)
