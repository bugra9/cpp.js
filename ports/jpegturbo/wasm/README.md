# @crossbind/port-jpegturbo-wasm

The **WebAssembly** build of the precompiled **libjpeg-turbo** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-jpegturbo](https://www.npmjs.com/package/@crossbind/port-jpegturbo)**.

## Supported targets
- WebAssembly (`wasm32`) — single-threaded
- WebAssembly (`wasm32`) — multi-threaded (needs `SharedArrayBuffer`; serve with COOP + COEP headers)
