# @crossbind/port-jpegturbo-wasi

The **WASI** build of the precompiled **libjpeg-turbo** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-jpegturbo](https://www.npmjs.com/package/@crossbind/port-jpegturbo)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
