# @crossbind/port-spatialite-wasm

The **WebAssembly** build of the precompiled **SpatiaLite** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-spatialite](https://www.npmjs.com/package/@crossbind/port-spatialite)**.

## Supported targets
- WebAssembly (`wasm32`) — single-threaded
- WebAssembly (`wasm32`) — multi-threaded (needs `SharedArrayBuffer`; serve with COOP + COEP headers)
