# @crossbind/port-sqlite3-wasi

The **WASI** build of the precompiled **SQLite3** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-sqlite3](https://www.npmjs.com/package/@crossbind/port-sqlite3)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
