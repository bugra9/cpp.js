# @crossbind/port-sqlite3-android

The **Android** build of the precompiled **SQLite3** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-sqlite3](https://www.npmjs.com/package/@crossbind/port-sqlite3)**.

## Supported targets
- Android `arm64-v8a` — 64-bit ARM (physical devices)
- Android `x86_64` — 64-bit (emulators)
