# @crossbind/port-zlib-ios

The **iOS** build of the precompiled **zlib** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-zlib](https://www.npmjs.com/package/@crossbind/port-zlib)**.

## Supported targets
- iOS device — `arm64`
- iOS Simulator — `arm64` (Apple Silicon)
