# @crossbind/port-zlib-wasi

The **WASI** build of the precompiled **zlib** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-zlib](https://www.npmjs.com/package/@crossbind/port-zlib)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
