# @crossbind/port-geos-wasm

The **WebAssembly** build of the precompiled **GEOS** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-geos](https://www.npmjs.com/package/@crossbind/port-geos)**.

## Supported targets
- WebAssembly (`wasm32`) — single-threaded
- WebAssembly (`wasm32`) — multi-threaded (needs `SharedArrayBuffer`; serve with COOP + COEP headers)
