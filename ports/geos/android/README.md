# @crossbind/port-geos-android

The **Android** build of the precompiled **GEOS** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-geos](https://www.npmjs.com/package/@crossbind/port-geos)**.

## Supported targets
- Android `arm64-v8a` — 64-bit ARM (physical devices)
- Android `x86_64` — 64-bit (emulators)
