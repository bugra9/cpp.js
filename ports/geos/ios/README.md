# @crossbind/port-geos-ios

The **iOS** build of the precompiled **GEOS** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-geos](https://www.npmjs.com/package/@crossbind/port-geos)**.

## Supported targets
- iOS device — `arm64`
- iOS Simulator — `arm64` (Apple Silicon)
