# @crossbind/port-zstd-wasi

The **WASI** build of the precompiled **zstd** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-zstd](https://www.npmjs.com/package/@crossbind/port-zstd)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
