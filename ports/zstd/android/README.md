# @crossbind/port-zstd-android

The **Android** build of the precompiled **zstd** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-zstd](https://www.npmjs.com/package/@crossbind/port-zstd)**.

## Supported targets
- Android `arm64-v8a` — 64-bit ARM (physical devices)
- Android `x86_64` — 64-bit (emulators)
