# @crossbind/port-expat-wasi

The **WASI** build of the precompiled **Expat** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-expat](https://www.npmjs.com/package/@crossbind/port-expat)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
