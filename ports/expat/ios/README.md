# @crossbind/port-expat-ios

The **iOS** build of the precompiled **Expat** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-expat](https://www.npmjs.com/package/@crossbind/port-expat)**.

## Supported targets
- iOS device — `arm64`
- iOS Simulator — `arm64` (Apple Silicon)
