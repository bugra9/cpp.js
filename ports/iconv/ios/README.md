# @crossbind/port-iconv-ios

The **iOS** build of the precompiled **libiconv** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-iconv](https://www.npmjs.com/package/@crossbind/port-iconv)**.

## Supported targets
- iOS device — `arm64`
- iOS Simulator — `arm64` (Apple Silicon)
