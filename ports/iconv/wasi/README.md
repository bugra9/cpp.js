# @crossbind/port-iconv-wasi

The **WASI** build of the precompiled **libiconv** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-iconv](https://www.npmjs.com/package/@crossbind/port-iconv)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
