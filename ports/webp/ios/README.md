# @crossbind/port-webp-ios

The **iOS** build of the precompiled **WebP** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-webp](https://www.npmjs.com/package/@crossbind/port-webp)**.

## Supported targets
- iOS device — `arm64`
- iOS Simulator — `arm64` (Apple Silicon)
