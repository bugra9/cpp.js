# @crossbind/port-webp-wasi

The **WASI** build of the precompiled **WebP** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-webp](https://www.npmjs.com/package/@crossbind/port-webp)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
