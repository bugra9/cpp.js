# @crossbind/port-openssl-android

The **Android** build of the precompiled **OpenSSL** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-openssl](https://www.npmjs.com/package/@crossbind/port-openssl)**.

## Supported targets
- Android `arm64-v8a` — 64-bit ARM (physical devices)
- Android `x86_64` — 64-bit (emulators)
