# @crossbind/port-lerc-wasi

The **WASI** build of the precompiled **LERC** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-lerc](https://www.npmjs.com/package/@crossbind/port-lerc)**.

## Supported targets
- WASI (`wasm32-wasip3`) — single-threaded command modules; run with `wasmtime` (47+)
